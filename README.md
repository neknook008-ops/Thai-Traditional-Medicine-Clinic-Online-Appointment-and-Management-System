# ระบบนัดหมายคลินิกการแพทย์แผนไทย

เว็บไซต์นัดหมายและจัดการคลินิกการแพทย์แผนไทย ศูนย์การแพทย์มหาวิทยาลัยวลัยลักษณ์ ใช้ Node.js built-in modules โดยไม่ต้องติดตั้งแพ็กเกจเพิ่มเติม

## เริ่มใช้งาน

ต้องใช้ Node.js 18 ขึ้นไป จากโฟลเดอร์โครงการรัน:

```powershell
node .\server.js
```

เปิด `http://127.0.0.1:4173` ในเบราว์เซอร์ และเลือก **สำหรับเจ้าหน้าที่** เพื่อตั้งค่าบัญชีผู้ดูแลระบบคนแรก บัญชีนี้ต้องใช้อีเมลและรหัสผ่านยาวอย่างน้อย 12 ตัวอักษร บัญชีผู้ใช้บริการแยกจากบัญชีเจ้าหน้าที่ และไม่มีสิทธิ์เข้าหลังบ้าน

กำหนด `PORT` และ `HOST` ผ่าน environment variables ได้ เช่น `$env:PORT=4174; node .\server.js` ค่าเริ่มต้น bind เฉพาะ `127.0.0.1` เพื่อไม่เปิดบริการออกสู่เครือข่ายโดยไม่ตั้งใจ

## ฟังก์ชัน

- หน้าสาธารณะแสดงข้อมูลคลินิก บริการ ราคา ระยะเวลา ประกาศ FAQ และช่องทางติดต่อ
- ปฏิทินตรวจสอบวันและเวลาว่างตามวันเปิดคลินิก วันหยุด ความจุ ผู้ให้บริการ เวลาทำงาน ช่วงพัก และการจองเดิม
- จองนัดด้วยบริการ ผู้ให้บริการตามเงื่อนไข วันเวลา และข้อมูลผู้รับบริการ พร้อมรหัสนัดหมาย
- ตรวจนัดด้วยรหัสและเบอร์โทรศัพท์ ขอเปลี่ยนวันหรือยกเลิกภายใต้เงื่อนไขที่กำหนด
- หลังบ้านมีแดชบอร์ด จัดการนัด ผู้รับบริการ ผู้ให้บริการ บริการ ตาราง/วันหยุด การตั้งค่า รายงาน บัญชีเจ้าหน้าที่ และประวัติการเปลี่ยนแปลง
- ข้อมูลระบบบันทึกถาวรที่ `data\clinic.json` และเขียนไฟล์แบบชั่วคราวก่อนแทนที่ไฟล์ข้อมูลจริง โฟลเดอร์ `data\` และ `.env` ถูกละเว้นจาก Git

## ข้อจำกัดและความเป็นส่วนตัว

ข้อมูลนัดหมายและบัญชีมีข้อมูลส่วนบุคคล ควรจำกัดสิทธิ์อ่านไฟล์ `data\clinic.json` และทำสำรองข้อมูลอย่างปลอดภัยด้วยกระบวนการของหน่วยงาน ขณะนี้ไฟล์ข้อมูลยังไม่ได้เข้ารหัส ไม่มีระบบสำรองอัตโนมัติหรือฐานข้อมูลหลายผู้ใช้ และไม่ควรนำไปเปิดบนอินเทอร์เน็ตโดยไม่มี HTTPS, การจัดการความลับ, การสำรองข้อมูล และมาตรการปฏิบัติการที่เหมาะสม ตั้ง `COOKIE_SECURE=true` เมื่อให้บริการผ่าน HTTPS

ระบบหลังบ้านใช้รหัสผ่านที่แฮชด้วย scrypt และ session cookie แบบ HttpOnly; session จะหมดอายุเมื่อรีสตาร์ตเซิร์ฟเวอร์ บัญชีและสิทธิ์จัดการได้ในระบบ แต่ยังไม่มีการยืนยันตัวตนหลายปัจจัยหรือการผูกกับระบบบัญชีองค์กร

ตัวเลือก SMS, LINE OA และอีเมลเป็นเพียงการตั้งค่า ยังไม่ได้เชื่อมผู้ให้บริการแจ้งเตือน การส่งออก CSV และพิมพ์รายงานทำงานในเบราว์เซอร์ ไม่มีการส่งออกฝั่งเซิร์ฟเวอร์หรือระบบสำรอง ทั้งนี้ระบบนี้เป็นซอฟต์แวร์จัดการนัดหมาย ไม่ใช่เวชระเบียนหรือระบบให้คำแนะนำทางการแพทย์
